# Contributing to the Las Palmas Coach Development Center

Thank you for helping improve the Las Palmas Little League Coach Development Center.

This project exists to support volunteer coaches, assistant coaches, team parents, and league leaders by providing practical, accessible, and development-focused resources.

We welcome contributions that improve:

- Coaching education
- Practice planning
- Player development
- Safety resources
- Team parent support
- Accessibility
- Mobile usability
- Documentation

---

# Guiding Principles

When contributing, please keep the following goals in mind:

1. Player safety comes first.
2. Player development is more important than winning.
3. Content should be beginner-friendly.
4. Coaching resources should encourage positive sportsmanship.
5. Information should be verifiable and current.
6. Official Little League rules should not be reproduced from copyrighted rulebooks.

---

# Submission Process

## Step 1

Fork the repository.

---

## Step 2

Create a branch.

Example:

```bash
git checkout -b feature/new-drill-library
```

---

## Step 3

Make your changes.

---

## Step 4

Test your changes locally.

Verify:

- Desktop layout
- Mobile layout
- Navigation
- Search features
- Dark mode
- Links

---

## Step 5

Commit your changes.

Example:

```bash
git commit -m "Add softball catching drills"
```

---

## Step 6

Submit a Pull Request.

Include:

- What changed
- Why it changed
- Screenshots if applicable

# Content Standards

Please:

✅ Use clear language

✅ Assume readers may be first-time coaches

✅ Keep explanations practical

✅ Focus on player development

✅ Cite official sources where appropriate

✅ Keep content age-appropriate

---

Please avoid:

❌ Negative coaching techniques

❌ Unsportsmanlike guidance

❌ Unsafe activities

❌ Copyrighted rulebook content

❌ Commercial advertising

---

# Accessibility

All new content should:

- Be readable on mobile devices
- Use accessible color contrast
- Include meaningful headings
- Include alt text for images
- Support keyboard navigation whenever possible

---

# Code Style

This project intentionally uses:

- HTML
- CSS
- Vanilla JavaScript

Please avoid adding frameworks unless approved by project maintainers.

The goal is to keep deployment simple and maintainable for future volunteers.
